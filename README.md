# Functional Programming Practical Week 6 <br> Makhambet Aidynuly IT-2504

This project contains the selected tasks:

- `Task01.cs` through `Task06.cs` - the required class tasks;
- `Task48.cs` - the easiest project-extension task from Tasks 46-49.

All other tasks, including the native C and C++ examples, have been removed.
Because the selected extension is Task 48, a C/C++ compiler is not required.
Only the .NET SDK is needed.

## Run the checks

The project targets .NET 10. Check that the .NET SDK is available:

```powershell
dotnet --version
```

Run the assertion runner from the project root:

```powershell
dotnet run --project .\PracticalWeek6.csproj
```

The runner covers the stated checks and an additional boundary or failure
assertion for every retained task. A successful run reports:

```text
All checks passed: 17
```

No Visual Studio Developer PowerShell, `cl.exe`, GCC, or other native compiler
setup is needed for this reduced task set.

## Project files

`bin\` and `obj\` are generated by the .NET SDK and are excluded from Git.
They can be recreated automatically by `dotnet run` or by building the project
in VS Code.
